# Неофициальный порт IRL-editor на Minecraft 26.2

Ветка `port/26.2` основана на `quaIett/irl-editor:port/1.21.11` (`cff57bb`) и
сохраняет исходную MIT-лицензию и авторство qualet. Это поддерживаемый
сообществом форк, а не официальный релиз автора.

## Статус

- Точечные источники и прожекторы проверены пользователем с включёнными тенями.
- Редактор, ImGui, автосвет, патчер шейдерпаков и теневые атласы запускаются в
  реальном клиенте Minecraft 26.2.
- Проверенная связка: Java 25, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2,
  Iris 1.11.4 и Sodium 0.9.2.

## Главное исправление

Minecraft 26.2 / Iris оставляет OpenGL clip depth в `GL_ZERO_TO_ONE`, тогда как
raw shadow renderer IRL и его приёмник ожидают NDC `[-1, +1]` с преобразованием
`depth = ndcZ * 0.5 + 0.5`. Из-за несовпадения поверхности ложно затеняли сами
себя: светились края, а плоскости рядом с источником оставались тёмными.

В соответствующей ветке `irl-core` добавлен `ShadowDepthConvention`. Для каждой
плитки прожектора и каждой из шести граней point-light cubemap он сохраняет
реальное состояние caller-а, включает `GL_NEGATIVE_ONE_TO_ONE`, depth range
0..1 и clear depth 1, а затем полностью восстанавливает прежнюю конвенцию.

GPU-тест воспроизводит старое значение глубины 0.8 вместо ожидаемого 0.9 и
проверяет 168 выборок глубины и 28 циклов восстановления состояния.

## Сборка

```powershell
$env:JAVA_HOME = '<путь-к-JDK-25>'
cd ../irl-core
.\gradlew.bat clean build publishToMavenLocal

cd ../irl-editor
.\gradlew.bat clean build
```

## Важные нюансы

- Сам depth fix находится в Java/OpenGL-коде и не требует повторного патча уже
  актуального IRLights-шейдерпака.
- Замена JAR не обновляет ранее созданный шейдерпак. После изменений `.irlights`
  definitions пакет надо создать заново.
- Сторонние шейдерпаки нельзя распространять без разрешения их лицензии.
- Перед стабильным релизом нужно поднять версию `irl-core`, расширить
  exception-safety `endPass()`, проверить AMD/Intel/Linux/macOS и добавить
  VRAM-профили для слабых GPU.

Исходный проект и архитектура: [qualet / quaIett](https://github.com/quaIett).
